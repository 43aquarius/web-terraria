# 泰拉瑞亚 Web · Terraria Web Clone

一个用 **Next.js 16 + TypeScript + Canvas 2D** 从零实现的网页版泰拉瑞亚复刻。所有像素美术均由**代码程序化绘制**（零外部素材、零版权风险），尽可能还原原作的核心视觉风格与玩法体验。

![tech](https://img.shields.io/badge/Next.js-16-black) ![lang](https://img.shields.io/badge/TypeScript-5-blue) ![style](https://img.shields.io/badge/%E5%83%8F%E7%B4%A0-16x16-green)

## ✨ 已实现特性

### 世界
- **程序化世界生成**：1100×340 格地形，起伏地表 / 泥土-石层过渡 / 黏土夹层 / 蜿蜒洞穴 / 铜铁银金四层矿脉 / 地表水塘与地下湖 / 树木与花草装饰 / 自然背景墙
- **昼夜循环**：480 秒一昼夜，9 关键帧天空渐变、太阳月亮圆弧轨迹、闪烁星空、三层视差云、双层远山剪影
- **彩色平滑光照**：天空光 + 火把/熔炉光源 BFS 传播，低分辨率光照贴图双线性放大
- **流体模拟**：水体下落 / 斜向流动，入水气泡与窒息条
- **草皮蔓延**：裸露泥土会逐渐长草，被覆盖的草退化

### 玩法
- **挖掘 / 放置 / 砍树**：工具匹配（镐挖矿、斧砍树）、伤害累积与四阶段裂纹、整树砍伐、多格家具整体放置与支撑判定
- **合成链**：徒手 → 工作台 → 熔炉（矿石锭）→ 铁砧，铜/铁/银/金四档工具与武器共 15 张配方
- **战斗**：挥砍判定、暴击、击退、无敌帧闪烁、伤害数字；4 种敌怪（绿/蓝史莱姆、僵尸、恶魔眼）昼夜差异化生成与 AI
- **生存**：生命再生、摔落伤害、溺水、死亡重生保护
- **背包系统**：40 格背包 + 10 格快捷栏，拖拽/右键拆半/堆叠合并，物品 tooltip
- **存档**：RLE 压缩 + localStorage，30 秒自动存档，读档恢复世界与玩家状态

### 表现
- **手感细节**：受击屏幕震动、落地尘土、挖掘碎块粒子、环境生物（白天蝴蝶 / 夜晚自发光萤火虫）
- **音效**：WebAudio 程序化合成（挖掘/破坏/放置/跳跃/受击/挥剑/拾取/合成/落水/死亡等 12 种）
- **UI**：心形血条、气泡条、小地图（敌怪/出生点标记）、深度与昼夜信息条、消息通知

## 🎮 操作

| 按键 | 功能 |
|------|------|
| `A` / `D` | 左右移动 |
| `空格` / `W` | 跳跃（按住跳更高，支持土狼时间） |
| `鼠标左键` | 挖掘 / 攻击 / 使用 |
| `鼠标右键` | 放置方块 |
| `滚轮` / `1-0` | 切换快捷栏 |
| `E` / `Tab` | 打开背包与合成 |
| `Esc` | 暂停菜单 |
| `M` / `H` | 静音 / 帮助 |

## 🚀 运行

```bash
bun install
bun run dev        # http://localhost:3000
```

## 📁 结构

```
src/game/            游戏引擎（纯 TS，无框架依赖）
  constants.ts       方块/物品/配方/敌怪定义
  textures.ts        程序化像素美术生成器
  world.ts           世界生成 / 水模拟 / 草蔓延 / RLE 存档
  lighting.ts        BFS 彩色光照
  sky.ts             天空/昼夜/视差背景
  sprites.ts         角色像素绘制
  entities.ts        AABB 物理 / 玩家 / 敌怪 AI / 掉落物 / 粒子
  engine.ts          主循环 / 输入 / 战斗 / 背包 / 存档 / 小地图
  render.ts          渲染管线
  sound.ts           WebAudio 音效合成
  store.ts           UI 状态订阅
src/components/game/ React UI 层（HUD / 覆盖屏）
public/terraria.html 单文件零依赖版（离线可玩）
```

## 📄 单文件版

`public/terraria.html` 是整个游戏的**单文件零依赖复刻**——不依赖 Next.js、不需要构建、不发起任何网络请求，双击即玩。访问 `/terraria.html` 或直接下载该文件在浏览器打开即可。
